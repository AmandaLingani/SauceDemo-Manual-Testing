# SauceDemo-Manual-Testing
Manual QA testing project for the SauceDemo web application, featuring test plans, test cases, bug reports, and test documentation.

## About the Project

SauceDemo is a demo e-commerce web application used to practise and demonstrate software testing skills. This project aims to apply software testing principles in a practical environment while documenting the testing process and results.

As SauceDemo does not provide a complete set of formal requirements or user stories for all functionality, some requirements and expected behaviours have been assumed for the purpose of this portfolio project. 

This project is an independent QA practice project created for learning and portfolio purposes.
