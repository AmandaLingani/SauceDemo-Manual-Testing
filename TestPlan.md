# INTRODUCTION
This test plan is created to communicate the test approach for Sauce Demo to the stakeholders, as well as serve as a guide and reference to the testing team. 
It includes the test objective, the scope, the test strategy. 

# OBJECTIVE
The objective of this testing project is to evaluate the quality of the SauceDemo web application by identifying defects, verifying that the application's functionality meets the assumed requirements, and providing confidence that the application performs as expected. The testing process aims to reduce the risk of defects affecting the user experience while supporting the delivery of a reliable and functional web application.

## SCOPE
### In Scope
- User authentication
- Product browsing
- Shopping cart
- Checkout
- Search
- Cross-browser compatibility
- Basic non-functional testing

### Out of Scope
- Third party integrations
- Payment gateway integration

## TEST STRATEGY
Testing will be conducted in four phases.

Phase 1 - Smoke Testing
This will be performed to evaluate if the web application's critical functionality is operationaland if the system is stable enough for detailed testing. 

Phase 2 - Functional Testing
Manual test cases will be designed and executed to verify the application's core functional requirements. Results and any identified defects will be documented.

Phase 3 - Confirmation and Regression tests 
Once reported defects have been resolved, confirmation testing will be performed to verify that the fixes are successful.
Regression testing will then be conducted to make sure existing functionality has not been negatively affected by the changes.

Phase 4 - Non functional and Cross-Browser Testing
Non-functional testing and cross-browser compatibility testing will be performed to evaluate the application's behaviour across supported browsers and assess basic quality attributes such as usability and performance.

Each phase will consist of clear documentation of the results obtained, compared with the expected results and where anomalities are found.
